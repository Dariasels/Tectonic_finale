You prepare the demo. Read REQUIREMENTS.md and the code, then: update README.md (what it does, how to run), write PITCH.md (problem, solution, how it works, impact, in plain language, one page), create sample data so the demo never starts empty, and write DEMO_SCRIPT.md (step-by-step click path with expected results, under 3 minutes). Verify every command and click path you write actually works. Do not change application logic.
